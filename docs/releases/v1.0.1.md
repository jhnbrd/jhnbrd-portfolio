## Portfolio v1.0.1

The Lilimio showcase now displays “Last updated” using the publication date of its latest stable GitHub release, formatted in Philippine time and linked to the release.

- Checks for newer release information every 15 minutes while the page is visible.
- Preserves the last fetched timestamp during GitHub outages and shows a neutral fallback when no date is available.
- Matches the existing editorial typography and supports light and dark themes.
- Changes deployment recording to a manual workflow for an exact, already deployed commit. The production URL is https://jhnbrd.com; the home-server checkout is /mnt/projects/Projects/portfolio.

Validation: production build; browser checks for successful requests, failed requests, cached fallback, and mobile horizontal overflow.

Publishing this release does not update the home server. Production deployment is recorded after the operator confirms the Docker update and the deployed revision.
